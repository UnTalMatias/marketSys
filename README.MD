## ¿Que viene a resolver?

La problemática que vendría a resolver este desarrollo de página web sería la facilitación de administración de una tienda, ya que una tienda con registros o archivos en físicos es sometible a más errores administrativos que una web, como una pérdida de documentos importantes, descontrol financiero y logístico, etc.

**Vamos a contar con los siguientes elementos para trabajar:**

* Visual Studio Code (preferiblemente) para editar código
* Stack XAMPP como entorno de desarrollo
  * Base de datos MySQL 
  * Servidor HTML Apache
  * PHP (Integrado con Apache)
* Presentación en PowerPoint
